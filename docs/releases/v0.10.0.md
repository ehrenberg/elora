# Elora 0.10.0 Beta

An intro for the adventure, a welcome screen on the first start, clearer guidance in the
adventure – and a big clean-up under the hood. **Online play needs 0.10 on both sides:**
0.9.x and 0.10 no longer play together (protocol version 7). Your save games and maps carry
over automatically.

## Download

| System | File | Note |
|---|---|---|
| Linux | `elora-0.10.0-linux-x86_64.AppImage` or `.tar.gz` | AppImage: make it executable and start it |
| Windows | `elora-0.10.0-windows-x86_64.zip` | **extract the whole ZIP** (right click → “Extract all”), then start `elora.exe` from the extracted folder |
| macOS (Apple Silicon) | `elora-0.10.0-macos-aarch64.dmg` | not signed: on the first start **right click → Open** |

Intel Macs are not built yet.

## New

- **Intro for every new adventure:** a short film of Tauwinkel falling grey and Elora setting
  out, narrated in German or English depending on the game's language, with the Tauwinkel
  music underneath. Skip it with Esc, Space, Enter or a click; watch it again from the pause
  menu of the adventure.
- **Welcome screen on the first start:** choose your name, the language and Elora's colours
  with a live preview. It starts in your system's language. Existing installations skip it.

## Adventure

- **Guidance only for what exists yet:** signposts, characters and shops no longer explain or
  sell things Elora cannot use yet (hook jerk, pull hook, stomp, climbing claws, the hammer
  before Klonk). Path signs to the Glutsandwüste and the Frostspitzen say why the way is still
  closed. Abilities Elora does not have yet appear as “???” in the skill tree; the forge says
  “not yet” instead of “not found yet”.
- **Signposts** are about twice as high and easier to spot.
- **Weather:** while an area's spring is still silent the weather is mostly dry and grey, with
  rain or a thunderstorm now and then – no more constant rain.
- **Fixed:** walking from a wooden platform onto ground at the same height no longer stops
  Elora at the edge.

## Under the hood

- Code, documentation and all internal names are now English; the game text stays German and
  English as before.
- **Save games of 0.9.x are converted on the first start** (`platz-1.esav` becomes
  `slot-1.esav`); afterwards 0.9.x can no longer read them.
- **Maps of 0.9.x, also self-made ones, keep working:** they are converted when loaded. Your
  own adventure maps move from `maps/abenteuer/` to `maps/adventure/`. The multiplayer maps now
  have English names (`dm-meadow`, `dm-desert`, `ctf-forest`, `ctf-night`); server
  configurations with the old names still find them.
- Error messages that players see are translated; logs, server console and command-line help
  are English. The start option `--abenteuer` is now `--adventure`.
- Security update of the HTTPS library used for the server list (rustls 0.23.46).

## Compatibility

- **Protocol version 7:** servers and clients must both be 0.10.
- Saves and maps from 0.9.x load and are converted automatically.
