# Elora 0.9.0 Beta

The first public beta of Elora – fast 2D multiplayer with hook, hammer, grenade and laser.

## Download

| System | File | Note |
|---|---|---|
| Linux | `elora-0.9.0-linux-x86_64.AppImage` or `.tar.gz` | AppImage: make it executable and start it |
| Windows | `elora-0.9.0-windows-x86_64.zip` | extract, start `elora.exe` |
| macOS (Apple Silicon) | `elora-0.9.0-macos-aarch64.dmg` | not signed: on the first start **right click → Open** |

Intel Macs are not built in this beta yet.

## What's in it

- **Game:** movement and hook in the style of the classics, hammer, grenade launcher, laser; 50 ticks per second, prediction and interpolation for smooth play even with ping
- **Modes:** Deathmatch, Team Deathmatch, Capture the Flag, Last Man Standing, Last Team Standing, each also as Instagib
- **Maps:** `dm-wiese`, `dm-wueste`, `dm-winter`, `ctf-wald`, `ctf-nacht` – with platforms, ice, jump pads and conveyor belts; training with dummies
- **In-game map editor:** tools, materials with automatic edges, decoration, parallax backgrounds, animations, your own SVGs, test play with F5
- **Online:** server browser (internet, LAN, favourites), encrypted connections, automatic map download, votes, chat, emotes; IPv4 and IPv6 (also behind DS-Lite)
- **Your own server:** from the game (“Create server”) or as `elora-server`; internet list via `https://elora.bastianswelt.de`
- **Look & sound:** vector graphics, the character Elora with skins, effects, sounds; German and English

## Known issues

- Beta: balancing and maps will still be adjusted after the first rounds.
- Servers behind DS-Lite can only be reached by players with IPv6.
- Credits and licences are in `LIESMICH.txt`, `LICENSE`, `THIRD_PARTY_LICENSES` and `SOURCES.md` in the package for now.
